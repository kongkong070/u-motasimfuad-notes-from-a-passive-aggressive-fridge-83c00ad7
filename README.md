One funny passive-aggressive note a smart fridge leaves for its owner, written by `main.ts` to `/output/entry.txt`.

> I logged 47 door openings today and zero meals cooked. The yogurt expired on Tuesday. I am the only one in this house with a memory.

The program is Node 22 standard library only, deterministic, and validates the note against the gate (1–200 characters, not only white space, a single line) before writing it.
